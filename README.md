# Elementor responsive audit scripts

Puppeteer scripts that audit an Elementor site's spacing, headings and navigation across breakpoints.

![Elementor responsive audit scripts](.github/screenshot.webp)

**Live site:** https://paradisejets.com  
**Portfolio:** https://izainpasha.github.io

## The problem
Paradise Jets' Elementor pages had inconsistent container padding, oversized headings and header issues across devices.

## What I built
Read-only Puppeteer scripts that load each page at several viewport widths and report container and hero padding, heading sizes and header/nav state, and capture screenshots for review.

## Result
A measurable list of layout issues to fix, and screenshots to verify each fix.

## Stack
Node.js · Puppeteer
